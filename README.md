Если вы не знаете что такое Firewall то сейчас обьясню:

Firewall (файрвол, межсетевой экран, брандмауэр) — это инструмент для контроля 
и фильтрации сетевого трафика между устройством (или локальной сетью) и внешней сетью (например, интернетом). 
Его главная задача — защитить систему от несанкционированного доступа и потенциально опасных соединений.
Подробней ищите в интернете.
