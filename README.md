Я подписал установщики методом самоподписи поэтому подпись надо будет добавить в доверенные. Вот как это сделать:

	1.Скачайте selfsigned.cer из релиза.
	2.Дважды кликните по файлу → «Установить сертификат».
	3.Выберите «Локальный компьютер» → «Далее» (потребуются права администратора).
	4.Выберите «Поместить все сертификаты в следующее хранилище» → «Обзор» → укажите «Доверенные корневые центры сертификации».
	5.Нажмите «ОК» → «Далее» → «Готово».
	6.Подтвердите предупреждение безопасности, нажав «Да».

	Способ быстрее (через командную строку):
	certutil -addstore "Root" selfsigned.cer

Если вы не знаете что такое Firewall то сейчас обьясню:

Firewall (файрвол, межсетевой экран, брандмауэр) — это инструмент для контроля 
и фильтрации сетевого трафика между устройством (или локальной сетью) и внешней сетью (например, интернетом). 
Его главная задача — защитить систему от несанкционированного доступа и потенциально опасных соединений.
Подробней ищите в интернете.
